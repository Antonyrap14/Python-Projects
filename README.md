# Python-Projects
# 🐍 Esercizi Python

Questa repository raccoglie una serie di esercizi svolti durante il mio percorso di apprendimento di **Python**.

## Contenuto

La repository contiene numerosi file Python (`.py`), ognuno dedicato a un esercizio o a un argomento specifico. Gli esercizi coprono diversi concetti fondamentali del linguaggio, tra cui:

* Variabili e tipi di dato
* Operatori
* Input e output
* Strutture condizionali (`if`, `elif`, `else`)
* Cicli (`for`, `while`)
* Funzioni
* Liste, tuple, dizionari e insiemi
* Stringhe
* Gestione delle eccezioni
* Moduli
* Esercizi di logica e problem solving

## Obiettivo

Lo scopo di questa repository è documentare il mio percorso di studio, esercitarmi con Python e consolidare le conoscenze attraverso la pratica.

## Come eseguire gli esercizi

1. Clona la repository:

```bash
git clone Python-Projects

```

2. Entra nella cartella del progetto:

```bash
cd Python-Projects

```

3. Esegui il file desiderato:

```bash
python nome_file.py
```

oppure, se utilizzi Python 3:

```bash
python3 nome_file.py
```

## Note

Gli esercizi sono stati sviluppati a scopo didattico e potrebbero essere aggiornati o ampliati nel tempo con nuove soluzioni e nuovi argomenti.
